# Content PGN sources

Every PGN here was extracted programmatically from a downloaded database file (never typed from memory), reduced to headers plus mainline moves, and then checked with `scripts/check_pgns.py`. Move data only; Lichess masters explorer needs an API token, so PGN Mentor (pgnmentor.com, free downloads) was the source for all but one game. The 10 golden games stay in `pipeline/tests/golden/pgn/`.

Identification: each game was matched on players + event + year + result (and round where known) and, for most games, a known move was confirmed at the right ply (e.g. Rotlewi 22...Rxc3, Steinitz 22.Rxe7+, Reti 9.Qd8+ / 11.Bd8#, Saemisch 25...h6 zugzwang). Modern games rely on the unique header match including Elo. No second source was cross-checked, so the owner sees the source per game here. Blunder games marked *engine-screened* were found by a depth-11 Stockfish scan of World Championship and Candidates games (a single move from a near-equal position that swings the evaluation by 300 cp or more), then kept as decisive, well-documented games; the main session should vet their fame. Where the plan listed colours the other way round, the database colours are used and noted.
