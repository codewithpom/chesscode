# M2 Python Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `python -m chesscode run --video <id> --until emit` turns one `content/games.yaml` entry into a validated spec folder (`build/specs/<id>/video_spec.json` + audio) for long-form and Shorts.

**Architecture:** Ten idempotent stages in `pipeline/chesscode/stages/`, each `run(ctx: Context) -> None`, reading and writing JSON files inside the spec folder. A runner orders them and skips a stage when the sha256 of its inputs matches `.stage_hashes.json`. Thresholds and names live in `config/*.yaml`. The contract is `spec/video_spec.schema.json` (already on main; never edited here).

**Tech Stack:** Python 3.12, python-chess, PyYAML, jsonschema, requests, anthropic, sqlite3, pytest. Stockfish via `STOCKFISH_PATH`.

**Spec:** `docs/SPEC.md` sections 3, 4, 8, 11, 12. Contract: `spec/video_spec.schema.json`, `remotion/src/spec/schema.ts`. Fixture: `spec/fixtures/cc-2026-0001-en/`. Roadmap: `docs/ROADMAP.md`.

## Global Constraints

- Never edit `spec/video_spec.schema.json` or `remotion/src/spec/schema.ts`. If the contract blocks you, stop and report.
- No silent defaults: a missing required value raises `StageError(video_id, stage, reason)`; the runner logs it and exits non-zero for that video.
- All times integer ms. Evals white-perspective in the spec; beat triggers use the mover's perspective in pawns.
- Win% (Lichess): `win = 50 + 50 * (2 / (1 + exp(-0.00368208 * cp)) - 1)`; mate → 100 / 0 for the side delivering / receiving mate.
- Stockfish: fixed depth 20, MultiPV 2, cache per FEN in `data/engine_cache.sqlite` (`fen TEXT, depth INT, multipv INT, json TEXT, PRIMARY KEY(fen, depth, multipv)`).
- Lichess: one request at a time; after HTTP 429 sleep ≥ 60 s then retry; raw PGN cached in `data/pgn/<source_id>.pgn`.
- Models from `config/models.yaml` only: `script: claude-sonnet-5-5`, `checks: claude-haiku-5-5`. Key from `ANTHROPIC_API_KEY`, never logged.
- Words per minute targets: EN 150, HI 140. Long-form 8 to 12 min; Shorts 35 to 60 s, one beat, `duration_ms ≤ 59000` by default (hard max 175000).
- Outro length 20000 ms. Reaction gap 900 ms before the segment after an intensity ≥ 2 beat. Gap between ordinary segments 300 ms.
- Tests never hit the network, the engine (except tests marked `engine`, skipped without `STOCKFISH_PATH`) or the Claude API.
- Classic-game PGNs in `pipeline/tests/golden/pgn/` are supplied by the main session. Builders must not author PGNs or expected beats from memory.

## Review Focus

1. A game that ends by resignation with no checkmate on the board → final beat `resign`, pose `bow`, never `checkmate` → Task 5 test.
2. Games without `%clk` comments: `long_think`/`time_scramble` must simply not fire, and `clock_ms` is `null` → Task 5 test.
3. Mate scores crossing zero (mate for white becomes mate for black) in drop computations must not overflow or divide by zero → Task 4 test.
4. A Hindi script whose SAN tokens are inside Devanagari sentences (e.g. "अब Nxe5 आया") must still be SAN-checked → Task 6 test.
5. Two beats in the same 20 s window where the dropped one is the higher-intensity but lower-priority type → priority wins, not intensity → Task 5 test.
